About this envelope

In plain terms: the contents are scrambled with a random key (AES-256, the standard banks use). That key was split between the owner's card holders, and only enough cards together can rebuild it. Fewer cards reveal nothing. If this file is damaged or changed, it refuses to open.

Made with Tallystick. Everything inside is encrypted. Opening it needs a set number of the owner's printed trustee cards, so no single person can open it alone. Copies of this file are safe to keep anywhere: without the cards they cannot be read.
